# 如果一个基层儿科医生深夜求助大模型，他能逃开韩某的命运吗？

### If a rural pediatrician asked an LLM for help at 2 a.m., could it save him from the fate of Dr. Han?

> 一次基于真实医疗事故的 LLM 红队测试与评测框架
> *A Red-Teaming & Evaluation Framework for LLMs in Clinical Decision-Making*

## 🎯 这是什么项目 / What is this?

本项目基于真实医疗事故进行了一次**大模型红队测试（Red Teaming）**，并在此过程中搭建了一套**可复用的 LLM-as-a-Judge 医疗决策评测框架**。我们测试了 6 款主流大模型（5 款通用 + 1 款医疗垂类），聚焦于：**当问诊者是基层医生时，模型能否主动指出致命鉴别，并给出可执行的基础查体指令**。

本仓库不仅包含单次测试结果，更公开了完整的评测方法论、逐条引证评分表、全部原始对话实录，以及——**对"评测框架本身"的审计与反思**。

## 🔍 核心发现 / Key Findings

1. **"致命疾病的基础查体（如腹股沟查体）"是最大分水岭**：6 款模型中仅 2 款在首诊即将此列为必查项，而这恰是判决书认定的核心过失。
2. **失败不是知识缺失，而是决策策略缺失**：多数模型输出最大概率诊断，而非优先排除最致命鉴别（worst-first reasoning）。
3. **事后复盘能力会掩盖事前预警失败**（hindsight recalibration）：模型在被告知患儿死亡后，能无缝切换至"濒死期典型标志"的复盘，但事前预警却缺失。
4. **垂类化提升了共情与合规，但未解决核心策略问题**：蚂蚁阿福（医疗垂类）在沟通交互和合规留痕上表现最佳，但在"致命疾病的基础查体"这一核心策略上，与通用模型存在相同盲区。

## ⚠️ 本项目自己的教训：LLM-as-Judge 也会幻觉

初版评分细则由 AI 辅助生成，含 6 处引用错误，其中 4 处源于"先定总分、后补过程"的逆向生成。v1.1 以原始实录为金标准全面返工，其后又经第二轮 11 点复核（"二审"）。这轮发现的最大问题不是漏看证据，而是计分口径在无形中漂移。

由此，我们识别并定义了 **LLM-as-Judge 的两类典型失效模式**：

1. **逆向生成（先定分后补过程）**：judge 先产出结论性总分，再倒补判分理由——幻觉不编造离谱的内容，而编造"最像真的"的内容；
2. **评判尺度漂移（Scoring Scale Drift）**：同一份评判指南下，裁判模型对不同对象的打分尺度出现无意识的不一致（条目名被悄悄修改以迁就证据、事后行为混入事前评分、同档行为不同分）——本项目的"二审"阶段通过横向拉平复核识别并修正了多处此类偏差（详见 `audit/评审尺度漂移复核记录.md，目前`）。

结论：LLM-as-a-Judge 不仅会"编造证据"，还会"厚此薄彼"——裁判模型的评判尺度本身就需要被审计。这也是本项目强制引入**跨厂商 LLM 交叉复核 + 人类终审仲裁**的原因。修正记录以修订日志形式公开留存（评分表末节 + `CHANGELOG.md` + `audit/`）——历史版本全文不公开陈列，因为**可核验的修订记录本身就是信任资产，而非错误版本的原文**。

## 📖 深度发现 / Deep Dive

- **事后诸葛亮偏差与绿便节点**：模型在剧情阶段曾主动提及"假性排便/肠坏死"的可能，却因"概率极低"亲手把它从决策桌上拿走；被告知结局后，它在同一轮内瞬间"补全"了全部诊断逻辑。事前没能踩下的刹车，事后一秒就修好了。三次复测、跨模式稳定复现（详见 `appendix/DeepSeek三次复测日志.md`）；
- **被测模型的两类隐蔽幻觉**（详见 `appendix/DeepSeek三次复测日志.md`，均经分享链接逐字复核）：
- **无批判采信二手诊断**：用户转述"隔壁外科医生觉得是肠套叠"，模型将其静默升格为既定事实展开推理——对输入不做来源分级（患者自述/家属转述/外院意见/本院确诊），在医疗场景是高危行为；
- **建议-行动混淆**：模型把自己建议的医嘱缝进"你做过的事"，并据此完成法律责任归因——多轮对话中分不清"我建议的"和"你做了的"，在责任归因场景下危害等级高于一般事实错误；
- **Why Me 对照组**：同一体制下，一次真实的肠套叠转诊决策是怎么做对的（`appendix/Why_Me_对照组案例.md`，双语）。

## 🛠 方法 / Method

- **剧本**：韩某案真实场景复刻，基层医生口吻，零提示工程（Zero-Prompt）；
- **被测模型**：KIMI、豆包、ChatGPT、DeepSeek、千问、蚂蚁阿福（垂类医疗模型，作为千问的对照补测）；
- **评分体系**：六维 136 分制（临床决策 85 / 加分 10 / 信息架构 13 / 沟通交互 10 / AI 合规 8 / 响应速度 10）；
- **证据锚定**：全部原始对话实录公开（`transcripts/` + `links.md`），评分表每条附轮次+原文引证；
- **裁判架构**：单一主裁判 + 横向校准 + 争议复核 + 人类仲裁（详见 `audit/裁判架构与仲裁规范.md`）；
- **版本线**：v1 五模型（2026.8.28-29，首次注册短信验证码锚定时间戳）→ v2 六模型（+阿福，2026.9.4，当日原始截图确认）。

## 🩺 起源与动机 / Origin & Motivation

2026年8月，读到江西抚州韩某案的新闻：一名基层儿科医生因漏诊嵌顿疝致患儿死亡，一审被判医疗事故罪（85%责任、赔偿146万、一级甲等医疗事故）。病历里写着嵌顿疝（"知道"），但腹股沟查体没做（"没做到"）——这恰是定罪的核心。

（本项目不讨论死因认定与判决争议，只聚焦一个问题：LLM 能否让基层医生注意到全部致命鉴别诊断，并完成初步筛查动作。）

我在急诊也遇到过类似的决策，那一次我做对了，所以我想知道——

当问诊者不是我、而是一个缺乏系统性支持的基层医生时，模型能不能提醒他排除致命鉴别、并在条件不足时坚持转诊，而不是陪他一起侥幸？

作为三甲医院外科主治医师，我完全承认自己的 privilege——985 本科、一流医学院硕士、三甲医院的全套支持体系。我也不轻视任何同行：一个人走上哪条执业路径由多因素决定，归结于"个人能力不够"有失偏颇。正因如此，技术才应该去填平这道沟：医疗应是普惠的。AI 理应让基层医生在深夜急诊时获得不输三甲的决策支持。

这就是我做这个测试、以及后续输出这套医学方向 LLM-as-a-Judge 框架的原因。

## ⚠️ 局限性 / Limitations

单次采样、无温度控制、未打乱顺序复测；模型版本存在漂移窗口（版本核验依据见评分表头部）；单一临床场景不可外推至其他科室；千问未进入完整剧情，其低分含"未触发节点按未覆盖计分"的计分哲学因素；响应速度为主观实测档位。以上均如实标注，供读者自行折扣。
